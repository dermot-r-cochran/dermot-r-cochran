# CLAUDE.md

Guidance for Claude Code when working in this repository.

## What this is

The GitHub profile README for `dermot-r-cochran`: one file, `README.md`, shown at the top of the profile page. There is no build, no CI and no other content.

## Rules for the README

- **It leads with the engineering work.** The thesis, the degrees and the repositories under *Where that line continues* come first. The novel and the photography appear under *Elsewhere* as personal projects.
- **Only public repositories are named or linked.** A private repository is never named here, described in detail or linked.
- **No workplace detail.** Nothing about an employer, its projects, its organisations or its systems appears here.
- **Each listed repository gets one line**: a link, then what it does in plain words. No badges, statistics or calls to action.
- **A change to what the README says about Dermot is his to approve**: a new line, a reworded description, a new section. Fixing a broken link, a rename that has already happened or a wrong date needs no approval and merges on its own.

## When another repository changes

`RELATED-REPOSITORIES.md` in `dermot-r-cochran/star-rangers` is the map of his public repositories. Its entry for this one lists the repositories named here. If a listed repository is renamed, retired or made private, update its line here and that entry in the same piece of work. When a line is added here, update the entry too.

## Landing changes

Use a branch and a pull request, even for one line, so the history keeps a record of each change. With no checks to wait for, a PR merges as soon as its diff reads right.
